🔥 FWI Prediction System

A machine-learning–based web application that predicts the Fire Weather Index (FWI) using environmental factors. The system combines:

Linear Regression ML model

FastAPI backend

Streamlit interactive dashboard

Dynamic Folium map

Analytical charts (bar and pie charts)

🚀 Features

FWI Prediction using 9 input parameters

Interactive sliders for user input

FWI Risk Classification: Low / Moderate / High / Extreme

Dynamic map showing risk location

Charts showing contributing factors

Simple, fast FastAPI backend

🧠 ML Model

Algorithm: Linear Regression
Inputs: Temperature, RH, Wind Speed, Rain, FFMC, DMC, DC, ISI, BUI
Output: Fire Weather Index (FWI)

🛠 Tech Stack

Frontend: Streamlit, Plotly, Folium

Backend: FastAPI, Uvicorn

ML: Scikit-learn, Pandas, NumPy

🏗 How It Works

User inputs weather values through sliders

Streamlit sends data to FastAPI

Model predicts FWI

Dashboard displays:

FWI value

Fire-risk category

Map marker

Bar + pie charts showing contribution
